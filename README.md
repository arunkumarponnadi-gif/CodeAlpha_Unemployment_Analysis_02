# 📊 Unemployment Analysis Dashboard

## Overview
This project analyzes unemployment trends in India using Python and Streamlit. It provides interactive visualizations and insights into unemployment patterns across different states.

## Features
- 📈 Unemployment trend analysis
- 🔍 State-wise filtering
- 🥧 Pie chart visualization
- 🔥 Correlation heatmap
- 📊 Employment statistics
- ⬇️ Download filtered data
- 🌐 Interactive Streamlit dashboard

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
